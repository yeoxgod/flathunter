# flat-hunter

Telegram-бот для поиска квартиры в Варшаве. Сам читает Otodom и OLX по вашим ссылкам, отсеивает лишнее,
оценивает каждое новое объявление (плюсы, минусы, красные флаги, что уточнить), пишет сообщение
на польском и отправляет его владельцу в WhatsApp, чат OLX или форму Otodom с ваших аккаунтов.

## Установка (Windows)

1. Распакуйте папку куда угодно, например на рабочий стол.
2. Дважды щёлкните **setup.bat**. Он сам:
   - поставит Python (если его нет) и все пакеты;
   - спросит, какой ИИ использовать: Claude по подписке Pro/Max, Gemini по бесплатному ключу
     Google AI Studio или Claude по API-ключу (поменять потом: **switch-ai.bat**);
   - откроет @BotFather: создаёте бота, вставляете токен, нажимаете Start у своего бота
     (chat id бот узнаёт сам);
   - откроет окно браузера: войдите в WhatsApp Web (QR с телефона), OLX и Otodom;
   - по желанию добавит бота в автозагрузку и запустит его.
3. Дальше всё в Telegram: бот сам спросит, что ищете, данные о себе и ссылки на выдачу.

Запуск в следующий раз: **start.bat** (или автозапуск). Бот работает, пока включён компьютер.

## Обновления

Напишите боту `/update` (или запустите `update.bat`): он скачает свежую версию с GitHub
(приватный `yeoxgod/flathunter`) и перезапустится сам.
В первый раз запустите `update.bat`: он попросит GitHub-токен только на чтение (откроет нужную страницу). Настройки, база и входы в сайты (папка `data`) не трогаются.
Бот также раз в несколько часов проверяет обновления и пишет, если они есть.

## Команды бота

- `/criteria` — что ищете, обычным текстом («2-3 комнаты до 5500, Мокотув/Воля, с мебелью, без агентств»)
- `/me` — данные о себе для сообщений (имя, работа, заезд, срок, жильцы, email и телефон для Otodom)
- `/links` — ссылки на выдачу: бот собирает их сам из `/criteria`; можно заменить своей ссылкой с сайта
- `/settings` — режим отправки, тест-режим, пороги, лимит в день, каналы, источники; `/hours 8 22`
- `/backfill` — прислать подходящие объявления за последние 2 суток (`/backfill 24` — за сутки); после сохранения ссылок бот предложит это сам
- `/login` — снова открыть окно браузера для входа
- `/status`, `/poll`, `/pause`, `/resume`, `/help`
- Ссылка на любое объявление OLX/Otodom → бот разберёт его сразу.
- Reply на карточку с текстом («добавь, что заедем с 1 декабря») → перепишет черновик.

## Откуда берутся объявления

Otodom и OLX не отдают страницы автоматическим запросам (403), а обходить их защиту бот не будет.
Поэтому объявления берутся от бота-агрегатора **@thewarsawrentbot**:
- **пересылка**: выделите сообщения от него → «Переслать» → этот бот (можно пачкой) — разберёт, отсеет, пришлёт карточки;
- **канал (автомат)**: закрытый канал, этот бот в нём админ, @thewarsawrentbot публикует туда объявления
  (если умеет); бот спросит подтверждение и будет читать канал сам;
- по желанию: **tg-login.bat** — чтение чата от вашего Telegram-аккаунта (официальный API).
Если сайт блокирует прямой опрос (403), бот сам выключает опрос этого сайта и пишет об этом.
Оценка идёт по тексту сообщения; если страница объявления недоступна, бот пишет это в карточке.

## Режимы отправки

- **По кнопке** (по умолчанию): в карточке «📤 Отправить», бот отправляет и присылает скрин.
- **Автомат**: отправляет сам, если оценка ≥ порога (по умолчанию 8) и нет красных флагов,
  через 3 минуты после карточки (есть кнопка «Отменить»), не больше N в день, только в заданные часы,
  с паузами 2-6 минут между сообщениями.
- **Тест-режим** включён изначально: бот вставляет текст, но не нажимает «Отправить», и присылает скрин.
  Выключите его в `/settings`, когда убедитесь, что всё работает.

Канал: если в объявлении есть телефон, WhatsApp, иначе чат OLX или форма Otodom.
Одному объявлению и одному номеру бот пишет только один раз. При капче, выходе из аккаунта
или незнакомой странице бот останавливается и присылает скрин, капчи не обходит.

## Важно

- **Риск блокировки.** WhatsApp и OLX запрещают автоматизацию; аккаунт могут ограничить,
  особенно в режиме «автомат». Для WhatsApp лучше запасной номер.
- **Не проверено на живых сайтах.** Парсеры и отправка проверены на макетах страниц:
  разметка Otodom, OLX и WhatsApp Web могла отличаться или измениться. Если что-то не находит
  или тест-режим присылает скрин с ошибкой, пришлите скрин, поправлю.
- **Gemini (бесплатный ключ):** на бесплатном уровне Google может использовать запросы
  (тексты объявлений и ваши данные из /me) для улучшения своих продуктов; есть лимит запросов в минуту/день.
- **Claude по подписке:** каждое объявление и каждая правка текста тратят лимиты подписки
  (общие с чатом). Бот не использует ANTHROPIC_API_KEY, даже если он задан в системе.
- Данные (настройки, база, сессии браузера, токен) лежат в папке `data`. Не передавайте её никому.

## Для разработчика

`python -m flathunter setup|run|login|check`; тесты: `python -m unittest discover -s tests -t .`
